# Скачать VALERA

**[Открыть страницу скачивания](https://github.com/MyLittleCutie/valera-downloads/releases/tag/v0.27.6)**

Игра VALERA, Windows x64. Скачивание открыто: аккаунт GitHub не требуется.

1. В разделе Assets скачайте `VALERA_0.27.6_Windows.zip.001`, `VALERA_0.27.6_Windows.zip.002` и `Unpack.cmd` в одну папку.
2. Запустите `Unpack.cmd`: он проверит целостность и распакует игру.
3. Откройте папку `VALERA_0.27.6` и запустите `VALERA.exe`.

Общий размер загрузки — около 2,55 ГБ. Godot устанавливать не нужно. Это полная сборка всех семи глав; исходники здесь не публикуются. Контрольные суммы — в SHA256SUMS.txt.
